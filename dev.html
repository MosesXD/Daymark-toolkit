DAYMARK · BUILD NOTES

Development

What Daymark currently does, what remains a prototype, and what needs further engineering.

WORKING

Current capabilities

  • Create, complete, filter and organize tasks into lists.
  • Use Today, Inbox, Upcoming, Someday and Logbook views.
  • Capture notes, manage routines and review weekly activity.
  • Run focus sessions and import/export workspace data.
  • Change theme and open the separate project estimator.

DATA & PRIVACY

Local browser storage

Workspace information is saved in this browser. It is not connected to an account or cloud sync. Export a backup before clearing browser data.

KNOWN LIMITATIONS

Not implemented

  • Integrations are preference/demo controls only; they do not connect email, calendars or health services.
  • No accounts, cloud sync, push notifications or backend.
  • The estimator uses demo assumptions, not a validated quote.
  • Full browser, accessibility and real-phone testing is still required.

NEXT DEVELOPMENT

Planned work

  • Finish mobile and keyboard interaction checks.
  • Add automated tests for tasks, focus sessions and import/export.
  • Design account, backup and sync behaviour before backend work.
  • Only add external integrations through explicit permissions and supported APIs.
